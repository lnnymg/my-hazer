LOVE LETTER WEBSITE — GITHUB PAGES

Files in this folder:
- index.html: the website content
- styles.css: the pink design and layout
- script.js: the click interactions

IMPORTANT: Upload all THREE files into the SAME top-level folder of your GitHub repository.
Do not upload only index.html. The file names must stay exactly as written.

To test on your computer, open index.html in a browser. Click “Open my letter”, then try the close button, “I need a little time”, and “Yes!”.

To publish: GitHub repository > Settings > Pages > Deploy from a branch > main > /(root) > Save.
